# 初学者视角审阅说明

审阅基准是“学生学过计算机基础，但没有使用或实现过大模型推理引擎”。遇到下面三类内容时，正式课件不再只给结论：

- 新对象首次出现时，先解释它是什么、保存什么、由谁使用。
- 新机制出现时，先给具体请求或数字例子，再给系统抽象。
- 论文结果出现时，同时说明实验条件、适用边界和不能直接推出的结论。

## 各讲补充重点

| 讲次 | 原先容易卡住的地方 | 当前补充内容 | 研究案例 |
| --- | --- | --- | --- |
| 第 1 讲 | 直接出现 token、logits、TTFT、TPOT、P99 和 goodput | 一次请求的完整时间线、采样概念、分位数与 goodput 数字例子 | vLLM、SGLang |
| 第 2 讲 | 不理解 Prefill/Decode 与 Transformer、Q/K/V 的关系 | Transformer 最小路径、Q/K/V 直觉、为何只缓存 K/V、逐步 Decode | SpecGen |
| 第 3 讲 | continuous batching、token budget、抢占缺少排队背景 | 到达率/服务率/利用率、队首阻塞、16-token budget 推演 | Sarathi-Serve、Llumnix、FastServe |
| 第 4 讲 | KV 公式、GQA/MQA、分页、引用计数过于跳跃 | 具体容量计算、碎片例子、块表、共享与释放规则 | vAttention、Mooncake、NEO、KV 压缩再评估 |
| 第 5 讲 | worker、进程、kernel、stream、TP/PP/DP 容易混用 | 部署对象、GPU 执行对象、metadata、集合通信 | DistServe、Mooncake |
| 第 6 讲 | 直接谈 FlashAttention、GEMM、量化，缺少瓶颈模型 | 算术强度、Roofline 直觉、GEMM/GEMV、量化对象 | FlashInfer、QServe、LServe |
| 第 7 讲 | baseline、控制变量、goodput、P99 缺少统计解释 | 假设与主张、变量分类、公平 baseline、样本数陷阱 | KV 压缩再评估、P/D 分离再评估 |
| 第 8 讲 | 默认学生熟悉 Git、Issue、PR 和多层测试 | Git 最小对象、可复现 Issue、测试层次、补丁证据链 | DEEPSERVE、GhostServe |

## 授课使用建议

每讲 48 页不需要平均分配讲解时间。前 22 页建立基本对象、核心机制和研究背景；第 23–46 页按四个深化模块展开概念、算例、全过程、易错点和课堂检查；最后保留 15–20 分钟综合练习并总结。授课时应允许学生画路径、算容量或写实验条件，而不是只听概念。
