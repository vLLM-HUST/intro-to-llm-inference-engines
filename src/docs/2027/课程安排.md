# LLM 推理系统（2027）

本课程首次开课年份为 2027 年。正式材料在仓库中统一分为三套入口：两小时课程介绍、8 讲主课程和 14 讲细分课程。8 讲版是默认授课节奏，每讲 2 小时、48 页，共 384 页；14 讲版保留 LaTeX Beamer 源码并发布 PDF，适合更细的周次安排。两套长课程共享同一知识主线，不是新旧版本。每讲均强调概念展开、逐步算例、全过程、易错点和课堂检查，并穿插 2024–2026 年推理系统研究案例。

1. 课程导论与评价指标
2. 请求生命周期与 Prefill / Decode
3. 请求调度与连续批处理
4. KV 缓存与状态管理
5. 推理系统架构与代码阅读
6. 执行优化与异构平台适配
7. 论文比较与实验验证
8. 开源实践与课程项目

课程仓库 `intellistream/intro-to-llm-inference-engines` 是正式发布的唯一来源。个人主页只引用仓库地址，不再保存课件副本；本地教学目录用于授课同步，更新后应核对 SHA-256 哈希。三套材料的入口和 8/14 讲映射见 `build/slides/2027/README.md`。
