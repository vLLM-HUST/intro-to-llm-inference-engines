# 《大模型推理系统与实践》（2027）

课程于 2027 年首次开设，共 16 学时，分 4 次授课，每次 4 学时。**第一次课完成第一个 MOD 策略改动和 CPU 测试**。课堂以一个调度插件贯穿四次课，后续原理用于解释和完善第一次课的实现。

## 四次授课安排

| 授课 | 4 学时安排 | 当次实践结果 |
| --- | --- | --- |
| 第一次 | 1 学时讲课程导论和请求路径（PPTX 第 1 讲选讲），1 学时做 [MOD 入门实操](../../site/tutorials/mod/index.html#first-lab)，2 学时讲请求生命周期（第 2 讲） | 建立本地分支，修改一条 BidKV 候选选择规则并跑通回归测试，记下改动前后的选择结果 |
| 第二次 | 2 学时讲调度和连续批处理（第 3 讲），2 学时讲 KV 缓存与状态（第 4 讲），用两讲的例子推演插件决策 | 确定所选扩展点、输入输出及回退条件，用 CPU 用例覆盖正常选择与放弃选择 |
| 第三次 | 2 学时讲系统架构和代码阅读（第 5 讲），2 学时讲执行优化与异构适配（第 6 讲），结合 [MOD 实现与注册](../../site/tutorials/mod/index.html#develop) | 完成插件实现、独立标识与清单，构建 wheel，记录宿主与协议兼容范围 |
| 第四次 | 2 学时讲论文比较与实验设计（第 7 讲），2 学时做 [MOD 验证、评测](../../site/tutorials/mod/index.html#package)和项目展示（第 8 讲选讲） | 在兼容宿主验证插件加载、调用与停用，整理相同条件下的基线和启用结果 |

**课前准备。** 安装 Git 和 Python 3.10 或更高版本，按 [MOD 教程](../../site/tutorials/mod/index.html#start) 获取固定提交、创建虚拟环境并运行测试。第一次课只需 CPU，无需下载模型或安装推理引擎。Nano-vLLM 实验用于观察请求、调度与 KV 状态。RIDE 教程用于独立 Controller 实践。

### 第一次课选页

1. 用第 1 讲 PPTX 第 3–8、11、13、21 页建立请求路径、阶段和指标概念。
2. 从第 8 讲 PPTX 前移第 3、5–6、10–11 页，介绍 Git 分支、最小补丁和测试层次，随后做 MOD 实操。
3. 回到第 2 讲解释 Prefill、Decode 和请求状态。第 8 讲第 15、17–18 页的证据包、汇报与互评留到最后一次课。

### 八讲课件主题

1. 课程导论与评价指标
2. 请求生命周期与 Prefill / Decode
3. 请求调度与连续批处理
4. KV 缓存与状态管理
5. 推理系统架构与代码阅读
6. 执行优化与异构平台适配
7. 论文比较与实验验证
8. 开源实践与课程项目

三套课件共享[课程内容基线](课程内容基线.md)中的术语、算例与请求主线。完整的 8/14 讲映射见[课件索引](../../../build/slides/2027/README.md)。
