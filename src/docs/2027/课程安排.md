# 《大模型推理系统与实践》（2027）

课程于 2027 年首次开设，共 16 学时，分 4 次授课，每次 4 学时。**MOD 实操安排在第二次授课的后 2 学时（总第 7–8 学时）**。学生先弄清一个请求如何推进、KV 容量不足时为什么要抢占，再动手修改策略。第三次完成实现与联调，第四次比较结果并展示。

## 四次授课安排

| 授课 | 4 学时安排 | 当次实践结果 |
| --- | --- | --- |
| 第一次 | 2 学时讲课程导论与评价指标（PPTX 第 1 讲），2 学时讲请求生命周期（第 2 讲）。结束前用 5–10 分钟预告项目并发出环境准备说明 | 能沿一次请求指出排队、Prefill、Decode 和 KV 状态释放的位置 |
| 第二次 | 1 学时讲调度和连续批处理（第 3 讲选讲），1 学时讲 KV 容量与抢占（第 4 讲选讲，结合第 3 讲的 BidKV 案例），2 学时做 [MOD 入门实操](../../site/tutorials/mod/index.html#first-lab) | 先手算两条候选请求的选择结果，再改一条 BidKV 规则、跑 CPU 回归测试，确定自己的插件选题和一条验收用例 |
| 第三次 | 1 学时讲宿主架构与扩展点（第 5 讲选讲），1 学时讲平台适配并定好对照实验（第 6、7 讲选讲），2 学时做 [MOD 实现、注册与联调](../../site/tutorials/mod/index.html#develop) | 完成独立标识、清单与 wheel，在兼容宿主验证加载、策略触发和停用，记录基线与测量配置 |
| 第四次 | 2 学时讲论文比较与结果解读（第 7 讲选讲），2 学时做 [MOD 评测结果](../../site/tutorials/mod/index.html#evaluation)展示与互评（第 8 讲选讲） | 展示已实现的插件与测试证据，比较固定模型、硬件和负载下的基线与启用结果，说明适用条件 |

**两次课之间的准备。** 第一次课后按 [MOD 教程](../../site/tutorials/mod/index.html#start) 安装 Git 和 Python 3.10 或更高版本，获取固定提交并跑通 CPU 测试。第二次课后，各组写清扩展点、预期行为和测试输入，再准备第三次课所需的兼容宿主。第三次课后完成固定负载的对照测量，供第四次课展示。

### MOD 相关选页

1. **第一次授课**用第 1 讲 PPTX 第 8、13、21 页串起请求路径、指标和项目目标，用第 2 讲第 7、9–15 页跟踪请求状态。
2. **第二次授课**用第 3 讲第 5–10、15、17–18、20 页讲批处理、KV 压力与抢占，配合第 4 讲第 5–8、10、17 页讲 KV 容量、分页和生命周期。进入实操时穿插第 8 讲第 3、5–6、10–11 页，讲分支、最小补丁和测试层次。
3. **第三次授课**用第 5 讲第 7–9、14、17–19、21 页定位宿主与代码扩展点，第 6 讲第 14–18、22 页核对平台条件，再用第 7 讲第 4–5、9–11 页固定对照变量和指标。
4. **第四次授课**用第 7 讲第 13–15、17、21 页分析证据，用第 8 讲第 15、17–18 页组织证据包、汇报与互评。

### 八讲课件主题

1. 课程导论与评价指标
2. 请求生命周期与 Prefill / Decode
3. 请求调度与连续批处理
4. KV 缓存与状态管理
5. 推理系统架构与代码阅读
6. 执行优化与异构平台适配
7. 论文比较与实验验证
8. 开源实践与课程项目

三套课件共享[课程内容基线](课程内容基线.md)中的术语、算例与请求主线。完整的 8/14 讲映射见[课件索引](../../../build/slides/2027/README.md)。
