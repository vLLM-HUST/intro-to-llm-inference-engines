# 《大模型推理系统与实践》（2027）

**8 次授课，每次连上 2 节，总共 16 节。** 每次使用一份主课 PPTX。「第几节」按全课程连续编号。两小时中英文速览是独立材料。

## 八次授课安排

| 授课 | 节次 | 两节课的任务 | 当次产出 |
| --- | --- | --- | --- |
| 第 1 次 · 课程导论与评价指标 | 第 1–2 节 | 跟踪请求路径，计算 TTFT、TPOT、吞吐与 Goodput | 一张请求路径图和一组负载、指标口径 |
| 第 2 次 · 请求生命周期与 Prefill / Decode | 第 3–4 节 | 跟踪请求状态，估算 KV 容量，分析分页、复用与回收 | 一个 KV 容量算例和一张状态图 |
| 第 3 次 · 请求调度与连续批处理 | 第 5–6 节 | 手推一轮连续批处理，判断 Token 和 KV 预算，分析抢占与回退 | 一轮调度推导和 BidKV 的固定输入 |
| 第 4 次 · 开源实践与课程项目 | 第 7–8 节 | 在 CPU 修改 BidKV 并跑回归，打开模板创建个人仓库 | 选择 b→a 的测试证据、项目选题与一条可执行验收用例 |
| 第 5 次 · MOD 实现与 CPU 测试 | 第 9–10 节 | 在本人仓库写失败用例，实现最小策略，补齐边界及回退测试 | 可测试的代码与待打包提交 |
| 第 6 次 · MOD 打包与宿主联调 | 第 11–12 节 | 构建并安装 wheel，验证宿主加载、触发、停用及回退 | wheel 和一份含 SHA、安装命令、调用证据的联调记录 |
| 第 7 次 · MOD 对照评测与结果分析 | 第 13–14 节 | 同版本、同负载运行关闭和启用两组，核对原始数据和统计口径 | 可复查的对照结果表、日志和原始数据 |
| 第 8 次 · MOD 复现验收与个人答辩 | 第 15–16 节 | 从冻结提交复跑，展示触发与对照结果并回答技术问题 | 最终仓库与 SHA、复现记录、个人答辩 |

必要原理集中在第 1–6 节，第 7–8 节开始实操。第 9–16 节全部用于个人项目实践，从实现推进到复现验收。

## 课前准备和提交

- 第 1 次课后按 [MOD 教程](../../site/tutorials/mod/index.html#start) 准备 Git 和 Python 3.10+，跑通固定版本的 CPU 测试。
- 第 8 节登记个人仓库、目标问题、宿主扩展点及验收用例。第 12 节登记联调记录。第 16 节交付、展示并答辩。
- 每人独立完成一个 vLLM-HUST 引擎 MOD，基础分 100 分。可为 yancan 负责的 RIDE Control Plane 另做一个 Controller 插件，第 16 节单独验收，最多加 30 分。
