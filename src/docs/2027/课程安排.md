# 《大模型推理系统与实践》（2027）

**8 次授课，每次连上 2 节，每节 45 分钟，共 16 节。** 每次使用一份主课 PPTX，合计 90 分钟教学时间。课件给出每节的时间分配、示范、练习及验收点。两小时中英文速览是独立材料。

## 八次授课安排

| 授课 | 第一节 · 45 分钟 | 第二节 · 45 分钟 |
| --- | --- | --- |
| 第 1 次 · 课程导论与评价指标 | 第 1 节。用事件表跟踪请求路径，给两类负载写观测计划 | 第 2 节。计算 TTFT、TPOT、分位数与 Goodput |
| 第 2 次 · 请求生命周期与 Prefill / Decode | 第 3 节。逐步追踪输入、采样和停止条件 | 第 4 节。估算 KV 容量，算共享前缀的真实回收量 |
| 第 3 次 · 请求调度与连续批处理 | 第 5 节。按 Token 和 KV 预算手推一轮 | 第 6 节。算 BidKV 的候选得分，写下实操断言 |
| 第 4 次 · 开源实践与课程项目 | 第 7 节。用 BidKV 做 CPU 热身，改公式并跑回归 | 第 8 节。建个人仓库，登记自己设计的行为、触发用例和边界预期 |
| 第 5 次 · MOD 实现与 CPU 测试 | 第 9 节。先写失败用例，再实现最小策略 | 第 10 节。补正常、边界与回退测试，冻结待打包提交 |
| 第 6 次 · MOD 打包与宿主联调 | 第 11 节。构建 wheel，隔离安装并验证注册 | 第 12 节。验证加载、触发、停用和回退，提交联调记录 |
| 第 7 次 · MOD 对照评测与结果分析 | 第 13 节。固定请求轨迹，在同一宿主做关闭与启用对照 | 第 14 节。从原始数据重算 Goodput、尾延迟与失败率，解释边界 |
| 第 8 次 · MOD 复现验收与个人答辩 | 第 15 节。按 README 从冻结提交复跑 | 第 16 节。提交最终版本，个人展示并回答技术问题 |

必要原理集中在第 1–6 节，第 7–8 节开始实操。第 9–16 节全部用于个人项目实践，从实现推进到复现验收。

## 课前准备和提交

- 第 1 次课后按 [MOD 教程](../../site/tutorials/mod/index.html#start) 准备 Git 和 Python 3.10+，跑通固定版本的 CPU 测试。
- 第 8 节登记个人仓库、目标问题、宿主扩展点及验收用例。第 12 节登记联调记录。第 16 节交付、展示并答辩。
- 每人独立完成一个 vLLM-HUST 引擎 MOD，基础分 100 分。选做项目为个人 RIDE Controller 插件，第 16 节单独验收，最多加 30 分。
