# 大模型推理基础设施：课程讲义提纲

## 使用说明

这份文件不再服务于单次短时报告，而是作为研究生课程的授课骨架。建议按 14 次课组织，每次课聚焦一个清晰主题，并配套阅读、讨论、小实验与项目推进。

## 课程材料如何联动

建议把整门课按“讲义定问题、tutorial 定路径、实验定证据、代码定控制点”的方式组织，而不要把四套材料拆开使用。

## 第 1 讲 课程导论

- 课程对象、目标与组织方式
- 为什么推理基础设施值得独立成课
- 什么是状态化推理系统
- 课程主线：调度、状态、执行路径、验证

### 本讲应回答的问题

- 为什么大模型服务系统的问题不同于模型训练问题
- 什么叫“系统边界”
- 为什么很多瓶颈来自状态耦合而不是算子本身

## 第 2 讲 工作负载与评价指标

- 离线推理、在线对话、RAG、智能体四类工作负载
- TTFT、TPOT、吞吐、P99、goodput、成本与稳定性
- 单点指标与端到端指标的区别

### 本讲板书重点

- 请求到达模式
- 长度分布
- 负载波动
- 评价指标之间的张力

## 第 3 讲 一次推理请求的完整链路

- API 接入与 tokenizer
- 队列、调度、batch 形成
- prefill 与 decode
- 流式返回与资源回收

### 推荐课堂动作

- 画出一次请求的时序图
- 让学生标出潜在排队点和状态驻留点

## 第 4 讲 请求调度机制

- request-level 与 iteration-level 调度
- continuous batching 的价值与边界
- 长短请求混部与队头阻塞
- 公平性、隔离与尾时延控制

### 论文精读

- Orca
- vLLM 中的 continuous batching

## 第 5 讲 KV Cache 管理

- KV 生命周期与容量压力
- PagedAttention 的设计直觉
- 块式管理、碎片控制与回收
- 前缀共享与复用条件

### 本讲应避免的误解

- 不要把 KV 只理解为 attention 的临时中间量
- 不要把 KV 优化等同于单个 kernel 优化

## 第 6 讲 状态管理与记忆组织

- DistServe 的 prefill/decode 解耦
- RAGCache 的知识对象缓存
- 会话记忆、知识缓存与 KV 的统一视角
- 状态搬运、复用与一致性

## 第 7 讲 推理系统架构

- 控制面与数据面
- 调度器、执行器、缓存层、通信层
- 开源 runtime 的模块划分
- 监控、日志与回归为何重要

## 第 8 讲 执行优化与异构路径

- 图执行、编译、launch 开销
- 放置策略、带宽约束与 I/O-aware 执行
- FlexGen 与 PowerInfer 的系统意义

## 第 9 讲 异构平台与国产算力适配

- 平台差异为何会改变瓶颈
- 能运行、能优化、能验证三个层次
- 迁移成本、收益边界与实验公平性

## 第 10 讲 论文比较方法与实验可信性

- 系统论文到底该怎么读
- 问题假设、机制、代价、边界、评测
- 如何避免“只看图不看假设”

## 第 11 讲 实验方法与可验证性

- 工作负载构造与对照组设置
- 端到端指标与局部探针
- 回归、热身、稳态与可复现性
- 如何识别不可信实验结论

### 课后任务

- 为课程项目写实验设计草案

## 第 12 讲 开源系统实践

- 进入真实代码库的方法
- 请求生命周期和 KV 管理的代码定位
- benchmark、脚本、日志与结果复核

### 课后任务

- 提交最小复现实验日志

## 第 13 讲 研究选题与课程项目工作坊

- 从瓶颈对象出发形成选题
- 从可控变量出发设计机制
- 从指标与实验出发验证收益
- 项目选题讨论与开题建议

### 课堂活动

- 小组中期汇报

## 第 14 讲 课程总结与最终汇报

- 回顾课程主线与关键方法论
- 项目最终汇报
- 如何将课程项目延伸为长期研究方向

## 课程讨论题库

1. 为什么说 iteration-level 调度改变的是系统控制点而不是模型本身？
2. 为什么长上下文会同时放大 prefill 代价和 KV 压力？
3. 为什么知识缓存问题不应被简单视作“外挂向量库问题”？
4. 为什么很多异构执行方法在单机实验中成立，却难以进入真实服务？
5. 为什么端到端服务质量验证与机制设计同样重要？

## 课程配套作业建议

- 作业 1：画出一个开源推理系统的请求生命周期图
- 作业 2：复现实验并比较两种 batch 策略下的 TTFT 与 P99
- 作业 3：分析 KV block 管理对显存利用率的影响
- 作业 4：对一篇系统论文做“假设-机制-边界-实验”四段式精读报告
- 作业 5：完成一个课程项目开题说明
