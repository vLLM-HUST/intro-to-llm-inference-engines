# 2027 年正式课程课件

2027 年为《大模型推理引擎入门》的首次开课年份。此目录是正式课件的唯一仓库发布位置。

## 八讲完整课程

`lectures/` 共 8 份 PPTX，每讲 48 页、2 小时，总计 384 页：

1. 课程导论与评价指标
2. 请求生命周期与 Prefill / Decode
3. 请求调度与连续批处理
4. KV 缓存与状态管理
5. 推理系统架构与代码阅读
6. 执行优化与异构平台适配
7. 论文比较与实验验证
8. 开源实践与课程项目

## 两小时快速介绍

`quick-intro/` 保留两个单文件版本：

- `LLM推理系统_两小时快速介绍.pptx`：60 页中文快速介绍。
- `llm_inference_systems.pptx`：124 页英文简洁快速介绍。
