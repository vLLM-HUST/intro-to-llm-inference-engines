# 2027 年正式课程课件

2027 年为《大模型推理系统与实践》的首次开课年份。此目录是正式课件的唯一仓库发布位置，按使用场景分为三套入口。三套材料共享 `src/docs/2027/课程内容基线.md` 中的术语、算例、研究案例边界和完整请求主线，不应理解为“新版、旧版、备份版”。

## 1. 课程介绍：`course-overview/`

面向单次讲座或首次接触课程的听众，保留两个单文件 PPTX：

- `LLM推理系统_两小时快速介绍.pptx`：60 页中文系统导向快速介绍。
- `llm_inference_systems.pptx`：124 页英文模型原理导向快速介绍，保留快节奏讲解方式。

两者共享术语、指标和完整请求主线，但根据听众调整展开顺序。两者均为独立的两小时介绍版，不计入 8 讲或 14 讲的讲次编号。

## 2. 八讲主课程：`lectures-8-pptx/`

共 8 份 PPTX，每讲 48 页，总计 384 页。以下编号用于按主题检索。第一次课搭配 [MOD 入门实操](../../../src/site/tutorials/mod/index.html#first-lab)，四次课的选讲与实践见[课程安排](../../../src/docs/2027/课程安排.md)。

1. 课程导论与评价指标
2. 请求生命周期与 Prefill / Decode
3. 请求调度与连续批处理
4. KV 缓存与状态管理
5. 推理系统架构与代码阅读
6. 执行优化与异构平台适配
7. 论文比较与实验验证
8. 开源实践与课程项目

## 3. 十四讲细分课程：`lectures-14-beamer/`

共 14 份由 LaTeX Beamer 生成的 PDF，适合按更细主题组织教学。可维护源文件位于 `src/slides/lectures-14-beamer/`，共享样式和补充示例也在该目录中。14 讲版与 8 讲版的主题对应关系如下：

| 14 讲版 | 主题 | 对应 8 讲版 |
| --- | --- | --- |
| 第 1–2 讲 | 课程导论；工作负载与评价指标 | 第 1 讲 |
| 第 3 讲 | 请求生命周期 | 第 2 讲 |
| 第 4 讲 | 请求调度 | 第 3 讲 |
| 第 5–6 讲 | KV 缓存；状态管理与记忆组织 | 第 4 讲 |
| 第 7 讲 | 推理系统架构 | 第 5 讲 |
| 第 8–9 讲 | 执行优化与异构路径；异构平台适配 | 第 6 讲 |
| 第 10–11 讲 | 论文比较方法；实验方法与验证 | 第 7 讲 |
| 第 12–14 讲 | 开源系统实践；课程项目工作坊；课程总结与汇报 | 第 8 讲 |

## 选择建议

- 两小时讲座：使用 `course-overview/` 中对应语言的单文件版本。
- 16 学时正式课程：使用 `lectures-8-pptx/` 和[四次授课安排](../../../src/docs/2027/课程安排.md)。
- 需要更细的周次安排、逐主题研讨或 Beamer 源码维护：使用 `lectures-14-beamer/`。

课程安排和初学者审阅记录位于 `src/docs/2027/`。个人主页及其他网站只引用本仓库，不再保存课件副本。
