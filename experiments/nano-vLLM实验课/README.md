# nano-vLLM 实验课总览

## 定位

本目录专门承接《大模型推理基础设施》课程的实验课文档。

这里的文档不是理论导读，也不是课堂问答，而是按“一次实验课一份讲义”的方式组织的详细实验说明。每份文档都应足够支撑一次完整课堂实践，包含：

- 本节实验目标
- 课前准备与环境检查
- 课堂操作步骤
- 观测点与记录模板
- 课后提交要求
- 教师与助教执行建议

## 与 tutorials 的分工

- `tutorials/`：偏理论导学、概念辨析、课堂问答、阅读提示。
- `experiments/`：偏实验课讲义、代码操作、插桩观测、结果记录。

两者围绕同一主题联动，但不再混写在同一份文档里。

## 使用建议

建议课程按以下方式配合使用：

- 先在 `slides/` 下的导出 PDF、`slides/tex/` 下的源码和 `docs/` 中讲清本周系统问题。
- 再在 `tutorials/` 中用问答方式收束概念、边界和推理链路。
- 最后在本目录中布置详细实验课任务，让学生围绕真实代码完成观察、修改和记录。
