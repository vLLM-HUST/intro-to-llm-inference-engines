# 实验二：请求生命周期观察

## 一、实验课定位

本节实验围绕“一次推理请求在系统中经历了什么”展开。目标是把第 3 讲中的生命周期概念落到可观测代码路径和阶段日志上。

本节实验不要求优化系统，而要求学生能够分阶段观察请求，并用长短 prompt 的对比说明 prefill 和 decode 为什么不能混成一个阶段看待。

## 二、本节实验目标

完成本节后，学生应能够：

- 把一次请求拆成创建、排队、prefill、decode、完成、释放几个阶段。
- 找出这些阶段在代码里的近似锚点。
- 通过长短 prompt 对比，说明 TTFT 和 decode 行为为何不同。
- 画出一张请求生命周期时序图。

## 四、课前检查

教师应确认：

- 学生已完成实验一。
- 学生已经知道请求入口和主循环的大概位置。
- 教学环境可以至少完成两组不同长度 prompt 的运行。

## 五、建议课时安排

- 10 分钟：回顾实验一的请求入口与主循环。
- 20 分钟：教师示范如何把请求拆成阶段。
- 25 分钟：学生自行插桩，记录阶段时间。
- 20 分钟：完成长短 prompt 对比表。
- 10 分钟：绘制生命周期时序图。
- 5 分钟：布置提交要求。

## 六、本节核心问题

为什么长 prompt 首先放大的通常是 prefill 代价，而不是所有阶段都被平均放大？

## 七、实验步骤

### 步骤 1：确认阶段划分

要求学生在自己的代码理解中明确以下阶段：

1. 请求创建。
2. 请求入队。
3. prefill 开始。
4. prefill 结束。
5. decode 循环开始。
6. decode 循环结束。
7. 请求完成。
8. 状态释放。

如果代码中没有天然的阶段标签，可以通过日志人为划分，但必须说明近似依据。

### 步骤 2：选择插桩点

建议插桩点：

- request enqueue
- prefill begin
- prefill end
- decode step begin
- decode step end
- request finish
- state free

建议日志格式：

```text
[timestamp] request_id stage prompt_len generated_len batch_size
```

### 步骤 3：构造长短 prompt 对照

至少准备两组输入：

- 短输入：16-64 tokens
- 长输入：512-2048 tokens

要求控制：

- 使用同一模型。
- 尽量固定输出长度。
- 说明是否使用同样的 batch 条件。

### 步骤 4：记录阶段结果

建议填写表格：

| case | prompt_len | output_len | total_latency | TTFT | avg_decode_step | prefill 是否主导 | 解释 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| short |  |  |  |  |  |  |  |
| long |  |  |  |  |  |  |  |

### 步骤 5：画生命周期时序图

时序图至少包含以下对象：

- Client
- Request Queue
- Scheduler / Engine Loop
- Model Runner
- Sequence / KV State
- Response

要求图中明确标出控制权从哪里切换，状态在什么时候被更新。

## 八、课堂讨论问题

1. 长 prompt 主要抬高了哪个阶段，证据是什么。
2. decode 为什么更容易和调度、并发、KV 驻留绑在一起。
3. 如果把 prefill 和 decode 当成完全同一种工作负载，会漏掉什么系统现象。

## 九、常见错误

- 用总时长替代阶段分析。
- 插桩点太少，无法区分 prefill 和 decode。
- 图里画了很多对象，但没有标出状态更新位置。
- 对长短 prompt 的对比没有控制输出长度。

## 十、课后提交要求

1. 一张请求生命周期时序图。
2. 一张长短 prompt 对比表。
3. 一段 500 字左右分析，解释 prefill 和 decode 的区别。
4. 一段日志摘录，证明阶段划分不是凭空假设。

## 十一、评分重点

- 阶段划分是否清楚。
- 日志与时序图是否对应。
- 解释是否能回到 TTFT、prefill 和 decode 的差异。
- 是否说明了近似划分的边界。

## 十二、与后续实验的衔接

本节的阶段日志和时序图会直接用于实验三和实验五：

- 实验三会进一步观察调度如何改变谁先进入下一阶段。
- 实验五会把本节的阶段日志纳入规范实验记录。
